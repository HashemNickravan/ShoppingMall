پروژه سیستم مدیریت فروشگاه دسکتاپ

این پروژه یک نرم‌افزار دسکتاپ برای مدیریت فروشگاه است که با زبان جاوا و کتابخانه Swing پیاده‌سازی شده است. داده‌های سیستم (کاربران، محصولات و سفارشات) به صورت پایدار در فایل‌های JSON ذخیره می‌شوند.

ویژگی‌های کلیدی

*   احراز هویت: امکان ثبت‌نام (Register) و ورود (Login) برای کاربران.
*   سطوح دسترسی:
    *   مدیر (Admin): امکان مدیریت کامل محصولات (افزودن، ویرایش، حذف) و مشاهده لیست تمام سفارشات.
    *   مشتری (Customer): مشاهده لیست محصولات، افزودن کالا به سبد خرید، مدیریت سبد خرید و نهایی‌سازی سفارش.
*   مدیریت سبد خرید: نمایش اقلام، محاسبه قیمت کل، امکان حذف کالا و پرداخت نهایی با کسر مبلغ از موجودی کیف پول کاربر.
*   ذخیره‌سازی داده‌ها: استفاده از فایل‌های JSON برای نگهداری اطلاعات کاربران، محصولات و سفارشات.

راه‌اندازی و اجرا

برای اجرای پروژه، مراحل زیر را دنبال کنید:

1.  پروژه را در محیط توسعه (IDE) مورد نظر خود باز کنید.
2.  به کلاس Main.java واقع در مسیر src/com/shoppingmall/Main.java بروید.
3.  متد main را اجرا (Run) کنید.
4.  پس از اجرا، فایل‌های پایگاه‌داده JSON به صورت خودکار در پوشه پروژه ایجاد خواهند شد.

ساختار پروژه و کلاس‌های اصلی

مدل‌های داده (Entity)
- User: اطلاعات کاربر شامل نام کاربری، رمز عبور، نقش و موجودی.
- Product: مشخصات محصول شامل نام، قیمت، دسته‌بندی و موجودی انبار.
- Order: اطلاعات سفارش ثبت‌شده.
- Cart: مدیریت آیتم‌های درون سبد خرید.

لایه دسترسی به داده (Repository)
- JsonProductRepository: خواندن و نوشتن اطلاعات محصولات در فایل JSON.
- JsonUserRepository: مدیریت ذخیره‌سازی کاربران.
- JsonOrderRepository: مدیریت ذخیره‌سازی سفارشات.

لایه سرویس (Business Logic)
- AuthService: مدیریت فرآیندهای ورود، ثبت‌نام و بررسی موجودی کاربر.
- ProductService: عملیات جستجو، افزودن و بروزرسانی محصولات.
- CartService: منطق مربوط به افزودن، حذف کالا از سبد و محاسبه قیمت نهایی.
- OrderService: نهایی‌سازی سفارش و ثبت آن در تاریخچه.

لایه نمایش (UI - View)
- MainFrame: پنجره اصلی برنامه که مدیریت تغییر بین صفحات مختلف را بر عهده دارد.
- LoginPanel / RegisterPanel: صفحات مربوط به ورود و ثبت‌نام.
- AdminPanel: داشبورد مدیریتی برای مدیر سیستم.
- CustomerPanel: داشبورد اصلی مشتری شامل تب‌های خرید و تاریخچه سفارشات.
- CartPanel: نمایش جزئیات سبد خرید و دکمه پرداخت.
