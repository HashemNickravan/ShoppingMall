این پروژه یک نرم‌افزار دسکتاپ مدیریت فروشگاه است که با زبان برنامه‌نویسی Java و کتابخانه گرافیکی Swing پیاده‌سازی شده است. در این سیستم، داده‌ها (مانند کاربران، محصولات و سفارشات) به‌صورت پایدار در فایل‌های JSON ذخیره می‌شوند.

 ویژگی‌های کلیدی
سیستم احراز هویت: قابلیت ثبت‌نام (Register) و ورود (Login) کاربران.
سطوح دسترسی:
ادمین (Admin): امکان مدیریت محصولات (افزودن، ویرایش، حذف)، مشاهده لیست کل سفارشات ثبت شده.
مشتری (Customer): مشاهده لیست محصولات، افزودن کالا به سبد خرید، مدیریت سبد خرید و نهایی‌سازی سفارش.
مدیریت سبد خرید: نمایش اقلام، محاسبه قیمت کل، حذف کالا و پرداخت نهایی با کسر از موجودی کیف پول کاربر.
ذخیره‌سازی داده‌ها: استفاده از فایل‌های متنی با فرمت JSON برای نگهداری اطلاعات کاربران، محصولات و سفارشات.
 نحوه اجرا (Getting Started)
برای اجرای این پروژه روی سیستم خود، مراحل زیر را دنبال کنید:

پروژه را در IDE خود باز کنید.
به کلاس Main.java واقع در مسیر src/com/shoppingmall/Main.java بروید.
متد main را اجرا کنید (Run).
پس از اجرا، فایل‌های دیتابیس JSON به‌صورت خودکار در پوشه پروژه ایجاد خواهند شد.
📂 ساختار پروژه و کلاس‌های اصلی
این پکیج شامل کلاس‌های زیر است:

User: اطلاعات کاربر (نام کاربری، رمز عبور، نقش، موجودی).
Product: مشخصات محصول (نام، قیمت، دسته‌بندی، موجودی انبار).
Order: اطلاعات سفارش ثبت شده.
Cart: مدیریت آیتم‌های درون سبد خرید.


JsonProductRepository: خواندن و نوشتن اطلاعات محصولات در فایل JSON.
JsonUserRepository: مدیریت ذخیره‌سازی کاربران.
JsonOrderRepository: مدیریت ذخیره‌سازی سفارشات.


AuthService: مدیریت لاگین، ثبت‌نام و چک کردن موجودی کاربر.
ProductService: جستجو، افزودن و بروزرسانی محصولات.
CartService: منطق مربوط به افزودن/حذف کالا از سبد و محاسبه قیمت نهایی.
OrderService: نهایی‌سازی سفارش و ثبت آن در تاریخچه.


MainFrame: پنجره اصلی برنامه که مدیریت جابجایی بین صفحات را بر عهده دارد.
LoginPanel / RegisterPanel: صفحات ورود و ثبت‌نام.
AdminPanel: داشبورد مدیریت برای ادمین.
CustomerPanel: داشبورد اصلی مشتری شامل تب‌های خرید و تاریخچه.
CartPanel: نمایش جزئیات سبد خرید و دکمه پرداخت.
